# CiteScope

**CiteScope is an independent research-oriented extension of GEO**, not a
rebranded copy.

Start with the project's [README](README.md), [architecture](docs/citescope/architecture.md),
and [research protocol](docs/citescope/research-protocol.md).

## Original CiteScope features

- Deterministic source-citation and quoted-excerpt integrity auditing
- Human-reviewed claim-level evidence benchmark and validation rubric
- Paired model comparisons with reproducible bootstrap intervals
- Recorded-response ingestion and HTML reports
- Controlled source-variant GEO experiments
- Opt-in, bounded modern-model response collection

Every capability has unit or end-to-end test coverage. No benchmark results or
real-world ranking improvements are claimed from the synthetic demos.
